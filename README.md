# Hospital Operations Analytics Project

## Overview
End-to-end data analytics project analyzing hospital operations, revenue, and patient insights.

## Tools Used
- Excel + Power Query (Data Cleaning)
- MySQL (Data Analysis)
- Power BI (Dashboard & Visualization)

## Project Structure
- `Hospital.sql` → SQL queries for analysis
- `Hospital_Dashboard.pbix` → Interactive Power BI dashboard
- `hospital_data.csv` → Cleaned dataset

## Dashboard Pages
1. KPIs Overview
2. Revenue Analysis
3. Operations Analysis
4. Patient & Insurance Insights
